# Reproduce L1

1. Open `colab/run_fibre_memory_colab_v1_3_2.py` in a Colab code cell.
2. Run the cell and upload `release_assets/gpt2_fibre_memory_v1_3_2.zip`.
3. Preserve the downloaded result ZIP and compare its protocol, configuration
   hash, seed and gate records with the archived evidence.

Notebook `-f` arguments are ignored by the launcher.
