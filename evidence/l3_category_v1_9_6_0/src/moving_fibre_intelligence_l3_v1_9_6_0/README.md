# MFI L3 v1.9.6.0 — prospective single-seed confirmation

This package freezes the successful v1.9.5.7 rank-8 writer configuration and evaluates it with a new writer seed (`82601`), a predeclared fresh stratified router split (`196001`), and four new bridge concepts (`dog`, `tokyo`, `japan`, `apple`).

No gate, optimizer setting, training step count, LoRA rank, response budget, KL threshold, address map, or checkpoint rule was relaxed. Held-out expressions remain excluded from training and checkpoint selection.

Passing requires every router, bridge, exact-access, training-expression, mixed-slot-margin, cyclic-reassignment, held-out-expression, response-budget, and endpoint-KL gate to pass. A pass constitutes prospective single-seed evidence in this restricted setting; it is not yet multi-seed or cross-model confirmation.

Expected A100 runtime: approximately 55–80 minutes after setup.
