# Claim boundary

This package fixes the L2 protocol, seed, data split, control arms, budgets,
training schedule and runnable implementation. It therefore supports exact
reproduction of the declared test.

The standalone development result archive is unavailable and not archived.
This directory must not be described as a complete independent evidence
archive, and no numerical result should be reconstructed from copied console
text or chat logs.

Held-out-expression access in the public evidence chain is instead supported by
the archived L3 integration and L4 transport records. This directory also does
not establish multi-seed, cross-model, L3 or L4 claims.
