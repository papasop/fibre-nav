# GPT-2 C10 A100：校正蒸馏与无在线修复写入

C9的12个训练状态和8个新状态，原始提议都能写出正确内容，但响应预算失败；外部一步响应校正后全部通过。C10测试能否把训练状态的校正效果吸收到学习到的写入器中。

## 固定方案

- 从C9最终冻结的写入器开始，复用其训练归一化。保留一份完全冻结的C9头作为基线。
- 监督只用12个C9训练状态的校正后端点，减去各自原准备态得到目标增量。C9的新状态端点不参与训练。
- 蒸馏MSE训练1000步，学习率1e-4；再预算缩放功能训练360个优化器步，学习率1e-5。
- 每个功能优化器步聚合四个状态，四类XOR各一个，变体每三步轮换。响应损失用位移除以0.002预算的Smooth-L1，权重1；最终验收门仍是原始硬门。
- 固定最后检查点，不用测试结果早停或选择头。冻结后才生成8个新局部准备态；范数0.375/0.75，固定新种子120031/120032、120131/120132、120231/120232、120331/120332。
- 新状态的教师是C9对应训练校正端点加同一扰动、再作响应校正的外部正对照，不替换预测。
- 冻结基线和蒸馏头分别仅作一次头前向，提交各自原始增量，实际前向验收。写入评估不调用Jacobian、SVD、回溯或响应校正。

读取裕度0.05、平均保护响应无穷范数预算0.002、平均锚点KL预算0.005均不变。所有成功状态必须产生输出翻转并保持未选内容。

## 重要区分

新准备态的构造仍使用C8保存的响应Jacobian和外部SVD，并允许预声明的响应校正。训练也仍使用外部自动微分。**零在线校正仅指冻结后的写入提议/提交/验收阶段。** 两个阶段有运行时保护和计数记录，不能混称为整个流程没有几何计算。

即使原始写入8/8通过，也只支持四种已训练输入邻域上的开发结果。请求输出位仍由运行时提供；C10不测试控制器，不证明自主XOR计算、独立模型确认或模型内部原生更新。

新状态不重采样，不按通过成绩替换样本。正对照不通过时保留完整分母8并报告条件不充分。原始候选失败时直接记录失败，不调用隐藏修复或教师回退。

## 保存与续跑

不限制会话时长；头和优化器每25步本地保存，蒸馏每500步、功能阶段每120步和评估检查点备份Drive。Drive只保留本C10目录最近3个已校验备份，父C9及更早结果不修改。
