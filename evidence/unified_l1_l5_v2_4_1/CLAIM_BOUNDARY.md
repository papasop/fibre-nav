# Claim boundary

v2.4.1-r1 is a prospectively frozen three-seed unified audit with **0/3
all-gates passes**. It supports three-seed coexistence of exact address
operations, selectivity, controls, response/KL eligibility and the declared L5
program criteria. It does not confirm strict held-out-expression access across
seeds, the complete L4 pair-geometry protocol, cross-model transfer,
gradient-free memory operation, autonomous instruction execution, arbitrary
program closure, capacity scaling or global transport.
