# Moving-Fibre F16 v3.2a developmental preflight

This four-seed study put all six online causal algorithms inside a
current-kernel transported eight-dimensional chart and compared restricted
Moving-Fibre F16 action with response-retraction cost at a common capability
endpoint. Natural gradient had minimum action in 4/4 seeds but minimum
retraction cost in 0/4. This supported the action candidate while exposing the
action/cost conflict tested by v3.2b and v3.2c.

The original executable files and raw result ZIP are preserved. This stage is
developmental and must not be cited as prospective confirmation.
