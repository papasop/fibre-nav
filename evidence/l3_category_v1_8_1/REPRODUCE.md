# Reproduce

In a fresh GPU Colab session, upload both files from `release_assets/` and run:

```python
%run /content/run_moving_fibre_intelligence_l3_v1_8_1.py
```

The launcher asks for `moving_fibre_intelligence_l3_v1_8_1.zip` and writes:

`/content/moving_fibre_intelligence_l3_results_v1_8_1.zip`

The frozen A100 record took approximately 66.6 minutes. Runtime can vary with
package installation, model download and Colab load.
