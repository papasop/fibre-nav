# Claim boundary

## Supported

R11 confirms, on five untouched seeds, a current-versus-source response-kernel
Pareto ordering under four frozen global response balls. The construction uses
a deterministic compact randomly initialized GPT-2 byte language model and a
shared 24-dimensional rank-4 LoRA chart. All numerical and response-budget
gates passed.

## Not supported

This evidence does **not** establish:

- superiority to AdamW;
- a training-speed advantage;
- pretrained GPT-2 fine-tuning performance;
- semantic or downstream-task transfer;
- superiority of inverse-Fisher conditioning;
- a universal optimizer ordering; or
- a global Picard theorem.

R10 is protocol development, not independent confirmation. R11 is the frozen
confirmation. R4/R5 cached-metric AdamW comparisons, if retained elsewhere in
the repository, must remain explicitly separate from this dynamic-kernel
result.
