# Claim boundary

## Supported

Within fresh seed `82931`, the frozen GPT-2 model, restricted rank-8 LoRA chart, four declared binary address cells, fixed prompt families and recorded response/KL budgets:

- a single shared parameter state passed exact and fresh held-out access after WRITE, selective OVERWRITE and SWAP;
- unselected cells retained their declared exact-read values;
- all operation endpoints passed response and KL gates;
- requested OVERWRITE and SWAP beat their corresponding wrong-operation and matched-norm random-kernel controls;
- local MOVE and RETURN reached their declared response sets and preserved exact access, held-out access and the positive held-out margin gate.

This is a prospectively frozen **single-seed confirmation candidate** following an adaptively developed protocol family.

## Not supported

- multi-seed or model-family confirmation;
- autonomous parsing or execution of instructions by GPT-2;
- gradient-free or ordinary inference-time memory operations;
- a general instruction-set architecture;
- arbitrary program composition or long-horizon error bounds;
- concept-level capacity scaling;
- in-place semantic rebinding beyond the declared binary content operations;
- global parallel transport or a globally certified fibre connection.

The operation names label externally executed experimental procedures. WRITE, OVERWRITE and SWAP use response-constrained projected-gradient parameter updates; MOVE and RETURN use local response retraction.
