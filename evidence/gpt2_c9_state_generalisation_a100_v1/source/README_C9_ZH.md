## 固定实验

1. 将全部12个已检查的C5准备态与教师增量用于训练，覆盖四种XOR输入。原C7排除输入明确转为训练数据。
2. 新建一个宽度32的WriterHead，固定种子99109。MSE训练2000步，再按既有温和功能目标细化240步。归一化只使用这12个训练状态。基础GPT-2和LoRA-A不更新，内存B没有损失优化器。
3. 固定最后的功能阶段检查点，冻结写入器。没有新状态上的早停、检查点选择或超参数搜索。
4. 此后才生成8个新准备态，每种输入2个，固定种子109031/109032、109131/109132、109231/109232、109331/109332，扰动范数0.375/0.75。使用C8保存的原准备态响应Jacobian作数值核投影，再执行预声明的响应校正。
5. 新状态教师由原教师端点加同一固定扰动并作响应校正构造。它是外部迁移正对照，不是独立重新优化的写入解；不进入训练，也不替换预测。
6. 每个状态仅一次写入器前向提议。分别报告原始提议和最多8步响应校正后的端点。校正每步最多6次回溯。最终仍需完整的读取/响应/KL门。

没有状态重采样、替换或通过样本挑选。任何新准备态/教师正对照不通过，完整请求分母仍为8，并单独报实验条件不充分。
