# Roadmap

1. Run R21b-r2 on the reused development set.
2. Require exact deterministic routing and use the retrieval oracle only to diagnose the remaining semantic ceiling.
3. If the oracle misses the semantic gate, stop router tuning and revise the generator/card representation.
4. If every development gate passes, freeze router, cards, decoding, and rubric.
5. Author at least 20 untouched prompts covering research and ordinary tasks, then run R21c without protocol changes.
6. Collect 200+ explicit human preferences before another weight update.
7. Only after robust evaluation, package an inference service and versioned profile updater.
