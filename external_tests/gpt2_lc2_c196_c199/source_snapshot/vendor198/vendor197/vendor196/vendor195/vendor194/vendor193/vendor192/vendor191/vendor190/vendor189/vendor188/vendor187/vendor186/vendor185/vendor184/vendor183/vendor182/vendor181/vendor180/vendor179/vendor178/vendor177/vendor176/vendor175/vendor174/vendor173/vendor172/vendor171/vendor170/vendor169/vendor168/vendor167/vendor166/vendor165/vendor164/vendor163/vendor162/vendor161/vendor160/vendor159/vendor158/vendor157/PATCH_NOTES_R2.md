# C157 R2：仅补齐基线阻断诊断

原 R1 正式运行在 FP32 零基线 logits 重放失败处停止：1 次 GPT-2 前向，0 次反传，0 个焦点态完成；不能据此判断 AD／有限差分一致性。原失败结果 SHA256：`010d48967abb9d33124c97b6ce8ff499ff99e21248d4ab1c653b06776d521831`。

R2 在原 guard 之前保存完整实际／归档 logits 和缓存响应数组、最大偏差、RMSE、差异条目数、最差坐标及运行环境／原 MODEL_PINS。FP64 基线若运行到，也在判断前保存同类材料。日志和 SUMMARY 会显示实测偏差。

原 `2e-9` 重放容差保持不变；没有换成 LC2 的 `0.002` 响应预算，没有替换归档基线，没有放宽旧运行判定。协议、C155/C156 输入哈希、方向、步长、模型、数据、26／16 的完整流程请求计数及父判定不变。R2 不增加模型调用；若基线仍有差异，预计仍在同处停止，但会保留可诊断证据。不要把 R2 阻断写成新训练态失败或导数结论。

环境或构建版本差异只作记录，不自动归因为误差来源。此版本没有尝试切换后端、重装 Torch、重新居中或选择更有利的计算条件。

必须使用配套 `C157_CPU_LAUNCHER_R2.py` 与 `C157_CPU_LAUNCHER_R2_BUNDLE.zip`。前端延续 R1 的真实 `launch157` 导入及协议／路径检查。
