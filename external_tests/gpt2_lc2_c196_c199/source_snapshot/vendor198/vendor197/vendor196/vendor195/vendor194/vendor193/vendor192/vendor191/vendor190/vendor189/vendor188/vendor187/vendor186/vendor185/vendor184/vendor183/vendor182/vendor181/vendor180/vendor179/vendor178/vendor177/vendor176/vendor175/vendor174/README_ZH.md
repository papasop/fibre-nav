## 为什么改变方向约束

C173记录显示：较大正步长下既存在最大响应坐标切换，也存在原响应损失为零的状态开始越过训练安全裕度。仅对当前最大响应损失的梯度施加共同下降约束，不能直接约束其他响应坐标或这些零损失态。

C174明确构造全部六个响应坐标对共享写入器系数的Jacobian，并把所有84态的正负两侧都放入同一个LP。此设计是否改善真实有限端点仍需本轮实测；不是因果归因、架构可行性或闭合保证。

## 固定离线步骤

1. **重放原固定头。** 第一轮原生84态先于AD，并与原C172锚点对应轮次比较；FP64锚点观测/KL按原2e-9容差重放。参考响应和logits不重定中心。最后重复FP64锚点和第二轮原生锚点。
2. **全部响应坐标AD。** 每态测六个带符号响应坐标、响应损失与guard损失各自对3×2×36系数的梯度。共672次标量反传，其中504次响应坐标反传，构成84个6×216系数响应Jacobian块。`new_Jacobians=84`明确报告；全模型参数Jacobian为0。部分失败保留已完成坐标反传和Jacobian块的计数。
3. **标量链一致性。** 从六坐标梯度重建原最大响应损失梯度，与独立标量损失AD比较。绝对容差1e-10、相对容差1e-8。该检查核对单位、符号及同函数链关系，不认证AD真实准确性。
4. **最多一个完整坐标LP。** 所有84×6×2=1008条约束保留，不按失败状态、当前最大坐标或近门槛子集筛选。guard梯度记录但不作为LP约束。
5. **精确记录代数检查。** 用有理数重算全部1008条带符号仿射响应约束，核对计划位移和实际binary64头端点之差。非空活跃集要求三个正探测头的最小记录裕度严格为正，才允许端点探测。否则停止并封装不完整结果；不重试、不换方向，不把未获得证书解释为不可行性证明。空活跃集固定零方向且不调用LP，不伪报严格下降。
6. **封存并测六臂。** 固定正负1e-4、3e-4、1e-3六臂，全部NumPy头、实际FP64点与仿射记录证书在首个探测前封存。梯度测量明确早于探测头封存。所有84态、六臂、失败与两轮原生门槛保留；不选头、不部署。

## LP的具体含义

在固定头p上，r_ij为第i态第j个带符号响应漂移，J_ij为其对系数的梯度。固定eta=0.001，训练安全值s=0.0018，并定义：

`b_i = max(s, max_j |r_ij|)`。

最大化公共无量纲裕度t，约束为：

`sign * (r_ij + eta * J_ij · d) / s + t <= b_i / s`

对全部i、j与sign∈{-1,+1}成立，且t>=0。自由坐标满足 `abs(p)<=0.125-0.001`，方向各分量限制在[-1,1]；其他方向坐标为0。没有逐行L2归一化。固定SciPy1.17.0、HiGHS双单纯形与单次求解预算，原求解器状态和原向量保留。

对原先超过0.0018的状态，b_i为当前最大响应；正记录裕度要求其线性预测最大值下降。其他状态以0.0018保护线性预测裕度。**b_i仅是训练方向问题的线性化边界，不替换原生0.002验收门槛，也不把已有失败态改判通过。** 实际浮点LP矩阵与精确原始仿射表达的舍入差别由独立记录检查暴露；求解器状态不是证书。
