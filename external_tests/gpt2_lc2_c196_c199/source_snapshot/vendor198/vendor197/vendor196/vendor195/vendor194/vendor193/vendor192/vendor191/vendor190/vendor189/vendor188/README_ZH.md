# C188：固定八步全响应坐标续训（CPU）

## 如何运行

在 Colab CPU 运行配套 C188_CPU_LAUNCHER.py，提示时一次上传 C188_CPU_LAUNCHER_BUNDLE.zip。无需解压，也无需上传科研结果 ZIP。程序从 Drive 固定路径读取 C155–C187 共33个原始结果包，先核对全部原包哈希。若 Drive 尚未挂载，会请求挂载；授权失败时保留失败总包，可挂载成功后重新运行。

工作进程限240分钟，依赖安装、合成自测、打包另计。成功或失败均输出一个包含源码、日志、门槛、逐态记录和部分结果的 ZIP，自动下载并在已挂载 Drive 中进行哈希核对备份。

## 本轮问题与固定范围

C187日志确认C186同次运行81/84→82/84，救回1态、破坏0态；这只是原训练集的结果。C188重新计算原C186并绑定原C187完整算术、精度、活动集、救回/失败及跨运行重放审计后，从原C186固定第8步最终头开始。

- 固定84个已暴露训练态，固定模型版本、LoRA-A、V、路由、prepared/raw状态及原C155缓存响应/锚分布参考。
- 8个离线更新槽，步长恒为0.001；每步全84态×6个响应坐标×正负两侧，共1008条LP约束。
- 672个系数响应Jacobian块，4032坐标梯度行，5376标量反传；最多8次LP。这里使用离线Jacobian与求解，不构成在线免校正执行。
- 2355次模型前向（含1682次functional FP64）；1176条有序记录；840个实际FP64点先封存后测量。
- 固定第8步头资格检查，全部84态，两轮原生完整门槛；FP64端点重复和336项原生/FP64响应裕度比较。不新增FP64完整接受门。
- 精确证书分别检查记录方向与实际binary64头差；若证书未满足，停止并保留记录，不切换步长或选恢复头。
- 活动集为空时按已登记规则记录零更新且不调用LP；仍保留全部8槽。

## 重放与接受门槛

首先重放原C186最终头。原生22维可观测量Linf≤0.0002、KL绝对差≤5e-6、原metric gates一致且实际参数点哈希一致；FP64可观测量与KL差均≤2e-9。原容差通过不代表逐值相等。不重设参考，不校准跨运行漂移。

训练响应安全目标0.0018与原生接受预算0.002不同。原生完整门槛仍由原协议计算，包含内容、未选内容保持、KL≤0.005、读取裕度≥0.05及固定半径；不放宽任何门槛。训练LP只约束响应坐标，guard仍记录且最终仍需接受全部门槛。
