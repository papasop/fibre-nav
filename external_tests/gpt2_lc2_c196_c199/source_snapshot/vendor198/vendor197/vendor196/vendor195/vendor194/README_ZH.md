## 固定协议

- 全部84个已暴露训练态保留，包括历史confirmation命名的状态；它们不能再计为新的未见确认态。
- 固定模型/版本、LoRA-A、V、路由、prepared/raw状态、原C155缓存响应和锚分布logit参考；只离线更新共享系数头。
- 八个更新槽、步长0.001。每步全84态六个响应坐标的正负两侧，共1008条LP约束，不只对两个失败态拟合。
- 672个系数响应Jacobian块、4032个响应坐标梯度行、5376次标量反传、最多8次LP。这是显式离线训练，不是在线免校正写入执行。
- 2355次模型前向，其中1682次functional FP64；1176条有序记录；840个实际FP64点在模型测量前封存。
- 每步分别检查记录方向和实际binary64头差的精确有理证书。未满足就停止并保留部分记录，不切换步长或头，不声称不可行。
- 活动集为空时按登记规则记录零更新且不调用LP，仍保留全部八槽。
- 只检查预定第8步头，全部84态，两轮原生完整门槛及最终FP64重复；输出336条原生/FP64端点响应裕度比较，不新增FP64完整接受门。
