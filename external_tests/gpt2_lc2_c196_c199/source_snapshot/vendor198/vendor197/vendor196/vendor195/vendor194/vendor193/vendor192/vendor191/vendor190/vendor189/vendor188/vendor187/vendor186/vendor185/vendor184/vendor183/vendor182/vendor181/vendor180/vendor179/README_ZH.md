# C179：C178固定8步续训的CPU只读归档审计

## 使用

在 Colab CPU 运行时运行配套 `C179_CPU_LAUNCHER.py`，提示时 **一次上传 C179_CPU_LAUNCHER_BUNDLE.zip**，无需解压，不要上传科学结果当作源码。挂载原 Google Drive 后，程序按原路径与固定 SHA256 读取 C155–C178 共24个原始结果ZIP。若原包移动，可在启动器 `INPUT_PATHS` 中填写对应键的本地绝对路径，文件内容仍须匹配固定哈希。

只生成一个结果总包，含源码、日志、摘要、全部明细和审计产物；工作失败也封装未完成结果。总包自动下载并尝试备份至 Drive，备份后比较 SHA256。源码BUNDLE不匹配会在执行科研代码之前拒绝。
