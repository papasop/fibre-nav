本轮检验：以原 C146 固定第12步控制为共同起点，三个局部控制向量的固定软路由，能否在相同84个已暴露训练态上改善原生端点验收。它是新的架构假设，不把C147审计解释为“全局向量不可能成功”的证明。

4. 挂载保存原结果的 Drive。程序自动定位并核对 C147、C146、C145、C143 原始科学结果 ZIP；它们不是待上传的配套源码包。若原包换位置，可填写启动器顶部对应的绝对路径；原内容哈希必须匹配。
5. 只输出一个结果总包，包含全部日志、报告、训练轨迹、冻结头、路由张量、失败记录及交付源码，并备份到 Drive。

## 固定对照

|分支|可训练参数（生产）|初始化|离线训练|
|---|---:|---|---|
|全局共享控制|36|原C146最终头|全84态，固定12步|
|三个局部控制器的软路由|108|三个原C146最终头副本|全84态，固定12步|

两臂目标、学习率0.0005、Adam规则、训练状态及原生验收门槛相同；分别重置动量。路由臂的参数数目与优化几何不同，因此结果不能单独归因于路由机制。

路由只读取 `u=V@(raw-prepared)`：prepared 为写前权重坐标，raw 为原冻结写入器的写前提案，并非写后模型测量。训练侧84行决定标准化和三个固定原型；首行加最远点初始化，固定8轮Lloyd更新，距离softmax得到连续权重。没有类别、状态ID、残差标签或失败态列表作为路由输入。实际几何聚类仍可能与类别相关，本轮不证明迁移能力。

只训练两个分支的系数；GPT-2、LoRA-A、原writer、原control、V、原特征及路由原型均冻结。标量AD计算有效36维控制的梯度，再以固定线性路由执行精确链式拉回。没有完整响应Jacobian、SVD、方程求解、教师、在线修复、回溯或检查点挑选。

## 请求与预算

重算C147归档算术，核对原C146最终头，之后才加载真实GPT-2 CPU。336次原生预检；84次零控制功能比较；两臂共168次初始功能比较；每臂12批、每批84态，合计4032次标量反传。两个最终头与336个提案全部封存后，四臂两轮测量672条原生端点；总模型前向6553次。

模型工作进程上限240分钟，协议测试与原包绑定测试各上限40分钟，实际Torch小模型烟测上限10分钟，依赖检查/安装另外计时。根据此前CPU表现，模型阶段预计需要数小时；这是上限而非完成保证。中断、超时或任何阻断错误都会打包失败结果；两个分支未全部完成时不授予训练资格。

最终四臂：raw、冻结C146、固定全局第12步、固定路由第12步。逐态保留通过、失败、救回与破坏。原响应线0.002、KL线0.005、读出裕度0.05及半径预算不变；训练安全线不能替代验收。没有新状态或排除类评估，不选臂、不部署。
