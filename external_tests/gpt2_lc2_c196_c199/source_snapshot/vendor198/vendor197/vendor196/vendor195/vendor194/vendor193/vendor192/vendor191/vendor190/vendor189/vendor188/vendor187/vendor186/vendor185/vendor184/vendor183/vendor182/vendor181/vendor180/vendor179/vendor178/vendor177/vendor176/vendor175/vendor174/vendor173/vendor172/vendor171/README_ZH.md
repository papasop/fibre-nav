本轮新增模型前向、反传、训练、拟合、LP、线性求解、Jacobian、SVD、状态制备、确认态和排除输入评估均为0。对父实验中8次LP的记录核对不计为新的LP；父LP内部线性系统数未知，保留null，不能改写为0。

点字节、接收单和归档计数不能证明真实时序、模型消费点的事实、未访问留出态或测量准确性。线性残差、FP32/FP64差异、瓶颈变化和局部损失趋势不构成曲率界、数值因果、收敛、全局可行性或泛化证明；不外推闭合需要多少步。
