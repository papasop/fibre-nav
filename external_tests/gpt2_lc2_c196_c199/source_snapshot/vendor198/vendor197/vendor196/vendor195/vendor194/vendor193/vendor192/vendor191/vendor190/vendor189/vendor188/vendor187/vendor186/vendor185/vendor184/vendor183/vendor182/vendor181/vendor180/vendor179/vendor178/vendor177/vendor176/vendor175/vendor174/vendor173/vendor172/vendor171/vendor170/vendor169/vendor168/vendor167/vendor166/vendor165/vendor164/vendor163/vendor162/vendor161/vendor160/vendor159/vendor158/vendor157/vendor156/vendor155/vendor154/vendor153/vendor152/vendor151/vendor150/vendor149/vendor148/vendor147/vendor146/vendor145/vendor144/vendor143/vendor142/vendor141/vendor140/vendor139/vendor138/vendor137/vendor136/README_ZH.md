## 本步改变什么

C135的统一法向标量没有超过原raw。C136把这个标量改为一组共享的逐方向控制参数，沿用C132已经冻结的36行正交响应基V，不构造新Jacobian或SVD。

`z = V @ (raw - prepared)`

`proposal(a) = float32(raw + V.T @ (a * z))`

一个36维a对全部状态共用，初始化严格为零。有效逐方向倍率为`1+a`；每次更新后逐坐标限制a到`[-1/8,1/8]`。原写入器、原行基、模型主干和LoRA-A均不优化。

为保持零控制原raw身份并保留梯度连接，提案不做径向裁剪。原实际更新半径门槛`20+1e-5`保持不变：超标既进入训练损失，也在最终验收中记失败，不能静默修复。

## 十二态全部是训练

使用原C132的全部12个历史中心。原6个几何构造中心与另外6个历史探测中心只保留来源标签，**本次全部用于训练，没有独立验证资格**。不加载或评价排除输入，不生成新态。

固定训练16步。每步在相同a上计算全部12态的标量反传，累加平均梯度；随后做一次手工float64 Adam更新：学习率0.003、betas=(0.9,0.999)、epsilon=1e-8、全梯度L2裁剪1、坐标投影到[-1/8,1/8]。总计192次标量反传。没有学习率搜索、早停、最优中途检查点或按态选择参数。

训练损失为全部12态均值：响应超安全预算的平方hinge均值与最大值、读出裕度hinge均值、KL hinge、更新半径hinge，以及0.001*mean(a²)。训练安全预算响应0.0015、裕度0.075、KL0.0045。**最终接受门槛仍为原响应0.002、裕度0.05、KL0.005及原内容与半径门槛。**

## 梯度与前向核对

加载GPT-2前强制执行6项真实CPU PyTorch小模型烟测，检查功能式参数替换的梯度连接、参数恢复、提案一致性、损失单位、Adam算术与冻结参数保护。

正式模型先重放12个制备态和24个原raw/投影端点。原包观测差≤0.0002、KL差≤0.000005，点身份与原门槛一致，否则停止。

之后，全部12态的零控制功能前向必须与本次正式raw前向一致：22维观测差≤2e-6、KL差≤2e-7，零控制点与原raw身份一致。完成这些检查前不允许梯度或优化更新。

训练通过`torch.func.functional_call`临时替换LoRA-B张量，只对a反传；不通过copy_、detach或.data切断提案到a的图。不优化GPT-2或LoRA-A参数，检查物理参数恢复与冻结参数/缓冲区身份。AD遵循float64控制到float32提交的计算图，不构成有限精度真实导数的独立认证。
