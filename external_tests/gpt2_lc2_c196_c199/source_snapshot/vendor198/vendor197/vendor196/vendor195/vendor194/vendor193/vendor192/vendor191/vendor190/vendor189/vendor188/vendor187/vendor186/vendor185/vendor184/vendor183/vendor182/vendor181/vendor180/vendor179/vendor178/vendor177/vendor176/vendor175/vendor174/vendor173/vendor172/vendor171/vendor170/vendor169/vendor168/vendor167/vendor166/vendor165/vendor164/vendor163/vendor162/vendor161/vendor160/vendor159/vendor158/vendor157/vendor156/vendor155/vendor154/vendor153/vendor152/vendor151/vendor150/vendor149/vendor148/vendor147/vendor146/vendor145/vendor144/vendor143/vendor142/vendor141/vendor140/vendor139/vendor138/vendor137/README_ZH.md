## 固定目标与日程

每态损失 L_i 与 C136 相同：响应在安全预算0.0015之外的平方 hinge 均值与最大值之和；16个读出裕度在0.075之内的平方 hinge 均值；KL在0.0045之外的平方 hinge；更新半径在20之外的平方 hinge；正则项0.001*mean(a²)。

全部12态的聚合目标为：

```text
F = 0.1 * mean(L) + 0.9 / 8 * log(mean(exp(8 * L)))
w_i = 0.1 / 12 + 0.9 * softmax(8 * L)_i
grad(F) = sum_i w_i * grad(L_i)
```

使用稳定的 log-sum-exp 实现。每态权重至少0.1/12，所有状态保留；高损失状态获得更大权重。每一步在同一向量上完成全部12态的未加权标量反传，随后计算权重并聚合梯度，才做一次更新。逐态损失、未加权梯度、权重及加权贡献全部归档。这是离线训练的权重调整，不是部署时的写后反馈或修复，也不保证约束一定满足。

固定24步手工 float64 Adam：学习率0.001，betas=(0.9,0.999)，epsilon=1e-8，聚合梯度L2裁剪1，逐坐标投影到上述区间。新实验共288次标量反传，只有第24步具备最终验收资格。没有早停、搜索、中途最优或恢复检查点替代。
