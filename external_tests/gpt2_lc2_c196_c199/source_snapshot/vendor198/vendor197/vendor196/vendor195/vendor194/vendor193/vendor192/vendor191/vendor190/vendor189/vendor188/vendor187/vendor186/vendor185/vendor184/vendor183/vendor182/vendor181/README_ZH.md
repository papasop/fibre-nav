# C181：C180固定八步续训的CPU只读归档审计

## 使用

在 Colab CPU 运行时运行 `C181_CPU_LAUNCHER.py`。提示时一次上传 **C181_CPU_LAUNCHER_BUNDLE.zip**，无需解压，不需要另选SOURCE.zip。不要把科学结果ZIP当作源码上传。

挂载原 Google Drive 后，程序按原路径及固定SHA256读取C155–C180共26个原始科学结果包。若原文件移动，可在启动器 `INPUT_PATHS` 对应键填写本地绝对路径，文件内容仍须匹配原哈希。BUNDLE包含固定源码，不包含26个科学结果包或模型权重。

工作成功或失败均生成一个结果总包，含日志、报告、逐态明细、重建算术与源码；尝试自动下载和Drive备份，备份后核对SHA256。配套源码哈希不匹配会在执行审计之前拒绝。
