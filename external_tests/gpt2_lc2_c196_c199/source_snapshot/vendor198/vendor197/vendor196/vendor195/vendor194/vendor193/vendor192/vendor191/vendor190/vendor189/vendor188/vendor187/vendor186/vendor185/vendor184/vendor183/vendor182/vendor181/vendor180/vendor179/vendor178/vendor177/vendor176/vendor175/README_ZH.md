# C175：C174全响应坐标方向与有限步只读审计（CPU）

## 使用

在 Colab CPU 运行 `C175_CPU_LAUNCHER.py` 的完整内容，只上传一次与其匹配的 `C175_CPU_LAUNCHER_BUNDLE.zip`，无需解压。启动器不内嵌科学源码。原 C155–C174 共20个科学结果由后续程序从原 Drive 路径按 SHA256 定位；不要上传结果包作为源码包。可选填写各 `Cxxx_ZIP` 的绝对路径，内容仍须匹配固定哈希。

程序仅需系统 NumPy，无 Torch、HF、SciPy 或模型下载。隔离 CPU 子进程最多60分钟，自测另计，不修改 notebook 进程的 GPU 可见性。成功或研究进程失败均生成一个结果总 ZIP，含报告、摘要、逐态与逐坐标明细、日志和源码；尝试以相同 SHA256 备份 Drive。输入缺失、哈希不符或证据不一致时保留未完成状态。

## 解释边界

`max(0.0018, 当前态最大响应)` 是训练线性化上限，不能替代原生0.002响应验收预算。精确证书只证明归档 binary64 响应与 Jacobian 的仿射算术；标量梯度链一致性不证明真实导数准确。

C175不执行模型前向、反传、训练、拟合、线性规划、方程求解、新 Jacobian 或 SVD。不增加状态、不接触新确认或排除输入，不选头/步长、不部署、不调整阈值、不改写 C174 判定，不计 LC2 通过。模型输出、KL、梯度、时序、非访问和保存点实际被模型消费均不能由本次只读审计独立证明。
