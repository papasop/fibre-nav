用途：C166已核对C165的4096次Frank–Wolfe迭代，但没有得到共同下降方向，也没有不可行性证书。C167独立重建原审计，然后对**全部原始R>0行**求一个有界共同下降方向；不会将5个门槛失败态单独作为优化子集。

## 固定问题

沿用C165的216维系数、精确C163最终头以及双向自由坐标掩码。全部84条归档梯度保留；原R>0行进入约束，包括零梯度。原响应安全量0.0018和原生验收门槛0.002均不改变。

以每行投影梯度的正L2范数缩放，求解：

`max t, B_i d + t <= 0, ||d||∞ <= 1, d_excluded = 0`。

两个固定HiGHS双单纯形LP：一个原问题，一个L1对偶。每个最多60秒；无多求解器搜索、无重启、无步长或头选择。原始求解器向量和残差全部保存。求解器状态不是证书。

独立验证器只使用Python Fraction和NumPy，不导入SciPy。它将归档binary64梯度、binary64行范数与最终方向视为精确有理数，重算：

- 全84态响应和保护损失的精确方向点积；
- 共同裕度下界 `L=min_i(-B_i d)`；
- 任意非负归一化对偶权重给出的上界 `U=||sum_i lambda_i B_i||1`；
- 严格验证 `L <= t* <= U`。

求解器计算使用舍入后的归一化矩阵；证书使用原binary64梯度除以原binary64正范数的精确有理数比值。因此数值求解精度不足会降低证书强度，而不会被误当成精确结论。

## 结果的含义

- `RECORDED_GRADIENT_COMMON_DESCENT_CERTIFIED`：所有活跃归档响应梯度与这个方向的精确点积均负，得到该线性问题的方向见证。
- `RECORDED_GRADIENT_STRICT_COMMON_DESCENT_IMPOSSIBLE_CERTIFIED`：精确非负对偶组合为零，证明该双向子空间内不可能让所有活跃归档响应梯度严格下降。没有接近零的判定阈值。
- `RECORDED_GRADIENT_FEASIBILITY_UNRESOLVED`：没有得到上述任一证书。求解器失败或超时不会生成任意替代方向。
- 没有活跃损失时单独报告空问题，不将空分母当成通过。

只有第二种情况且精确对偶上界等于零，才报告严格共同下降不可行；很小的正上界仍然不等于不可行。原问题最优共同裕度区间可很宽，不宣称自动获得最优解。

## 证据边界

本轮新做的是**离线方向优化**，会如实记录两次线性规划，求解器内部线性系统数未知。没有新模型训练步骤、头拟合、模型前向、反传、新Jacobian或SVD。不生成新参数头，不测有限步长端点，不部署方向。

证书仅关于归档浮点梯度定义的线性问题；不证明真实导数准确、保护项下降、有限写入接受、全参数可行性或不可行性、因果机制或排除输入泛化。所有84态保护项和非活跃响应项的点积保留供后续判读，它们并非本次LP的保护约束。C165/C166原判定、训练分母和LC2开放状态保持。

若得到方向，下一轮才能预登记固定有限步长、封存所有提议并在真实模型上检查全部84态原门槛。若得到不可行证书，其结论也只限当前局部线性子空间。两者都不直接闭合LC2。
