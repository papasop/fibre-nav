# C142：C141冻结确认只读审计（CPU）

下载 `C142_CPU_LAUNCHER.py` 与 `C142_CPU_LAUNCHER_BUNDLE.zip`。将启动器全文粘贴到 Colab 一个代码单元，提示时只上传这一份 BUNDLE.zip，无需解压。启动器不内嵌科学源码；不需要GPU、Torch、HF或模型下载，仅需现有NumPy。

## 固定科学输入

1. C141 R1完成的科学结果包，SHA256：`360e97c239a98258599bab5addfff53c79a50e21e7140ff33f2cd9739a9dc802`。
2. C140完整训练科学结果包，SHA256：`3a018a3845ccd6281f654a4b0e0d2c36fb8df335fbca69494ca5a0e290f15741`。

程序按固定路径从Drive读取。若原文件移动，填写启动器顶部 `C141_ZIP` 或 `C140_ZIP`；字节仍须匹配固定哈希。不要选择早先C141超时结果、启动器ZIP或C140源码包。

## 工作范围

- 对两原ZIP重新校验全包哈希、成员清单与成员哈希；固定核对C141 R1交付源码，不执行归档内源码。
- 从C140原始第12步更新、最终冻结向量、原basis、writer和control实际张量重新绑定C141使用的候选；不重算C140全部12步训练，也不独立验证历史梯度。
- 从C140已知训练中心和固定V、种子、范数重建C141全部48个float32制备坐标；无新状态准备或模型测量。
- 重建全部48个写前raw映射、完整3211维特征（含3147前缀与64维尾部）、C137/C140提案及144个封存点。
- 重算96条制备门槛、288条端点门槛、重复一致性、三臂配对救回/破坏，核对摘要和逐条副本；原分母和失败全部保留。
- 将全部144条已知原生重放与C140原生参照重新比较。C141已知制备曾使用C132/C139的历史参照，本次不打开C132–C139原包，不声称独立重算那些历史比较标量；另行直接比较C140制备参照。
- 分别报告两档预登记范数0.125/0.375、各输入类与全48态。小范数子集不能取代全48态确认，不能通过事后缩半径改写C141原结论。
- 对两轮全部48态、C137和C140两个补偿臂保留192条有符号响应诊断，另列C140所有失败。实测补偿作用为候选响应减raw响应，不是新模型测量或独立的算子/预测器误差估计。

原C141科学确认失败判定不改写。已暴露状态继续记为开发可见；本次无新候选、训练、部署、拟合、方程求解、Jacobian或SVD。无排除输入评估，LC2及单折均未闭合。

## 时间与输出

合成测试上限40分钟、只读工作进程上限20分钟，分别计时。运行时依机器速度而异，超时会保留未完成判定。CPU子进程使用两线程且隐藏GPU，不修改Colab内核GPU环境。

成功或失败只生成一个结果总包，包含日志、源码、输入绑定、审计报告、逐态残差、统计与结果清单；尝试备份Drive并下载。

重点文件：`SUMMARY.json`、`REPORT_ZH.md`、`RECOMPUTED_CONFIRMATION_SUMMARIES.json`、`RECOMPUTED_PAIRED_EFFECTS.json`、`ALL192_SIGNED_RESPONSE_EFFECT_DIAGNOSTICS.json`、`C140_FAILURE_DIAGNOSTICS.json`。

## 证据边界

`complete=true`仅表示归档审计完整，不表示C141确认通过。归档一致性不能独立证明测量精度、非访问、时序、真实导数、收敛、曲率或硬件因果。响应差值的恒等分解不能保证下一候选通过，也不作为在线修复。C142不是新的泛化实验。

`LOCAL_VALIDATION.json` 与 `LOCAL_TEST_LOG.txt` 记录交付前合成验证。未持有两原科学ZIP，交付前不声称已经完成真实原包C142审计；实际原包审计由Colab运行。
