## 固定对象与目标

固定 C155 `small_step12 / cyclic_rate_1e4` 的 **before** 完整 `(3,2,36)` 头；原 after-before 仅用于固定方向差分，未作为训练更新。固定原V、全部84态 prepared/raw、原写前路由和顺序。所有状态继续属于训练域。

连续 FP64 映射沿用 C159：`P(alpha)=P0+alpha*deltaP`；显式左结合的三专家权重和；`u=V@(raw-prepared)`；`theta=raw+V.T@(e[0]*u+e[1]*roll(u,+1))`。可微路径不包含最终FP32转换。七个系数张量、588个本次Torch FP64点、588个原FP32点与1008条请求在模型加载前封存。原FP32点通过受信原NumPy映射精确重建，新连续点与独立NumPy公式核对。

完整目标：

- 响应：`R=relu(max(abs(response))/.0018-1)^2`。
- 读取：16个带符号读出裕量的 `.075` hinge 平方均值。
- KL：`relu(KL/.0045-1)^2`。
- 半径：`relu(norm(theta-prepared)/20-1)^2`。
- 正则：`.001*sum(e^2)/rank`。
- 聚合：`J=.9*max(R)+.1*mean(R)+mean(其余四项)`；对精确并列最坏态平均其梯度权重。

**参考固定在模型加载之前。** FP64响应使用原C155缓存FP32响应的精确FP64转换；KL使用原C155 FP32全零基线logits的精确FP64转换，并在FP64重新计算概率。新运行FP64基线仅描述性报告，不替换目标参考、不依据结果选参考。

原生资格表使用实际物理FP32坐标提交、原缓存FP32响应和原FP32基线logits，按FP32均值/减法/KL计算。响应 `.002`、KL `.005`、读取 `.05`、半径 `20+1e-5` 等原门槛均保留。额外FP64重算的native KL只作诊断，不代替门槛。准备态有效性来自归档绑定，未重新准备或独立重放准备过程。
