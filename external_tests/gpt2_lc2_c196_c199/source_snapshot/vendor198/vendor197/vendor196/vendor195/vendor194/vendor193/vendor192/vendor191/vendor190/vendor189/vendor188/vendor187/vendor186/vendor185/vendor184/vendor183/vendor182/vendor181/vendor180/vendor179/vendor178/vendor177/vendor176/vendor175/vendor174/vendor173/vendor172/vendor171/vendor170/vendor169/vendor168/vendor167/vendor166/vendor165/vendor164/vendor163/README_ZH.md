## 固定方案

C162原包的逐步记录显示，两最坏态在切换时的响应损失梯度余弦约为−0.999996，第4、5步记录聚合梯度与实际更新的点积为正。这是训练记录诊断，不证明梯度真实正确、优化器因果或结构不可行。

本轮采用一个预注册研究方案：

`rho = 0.01 * log(mean(exp(R / 0.01)))`

`J_smooth = 0.9*rho + 0.1*mean(R) + mean(G)`

使用减去最大值的稳定log-mean-exp实现；全部84态参与。`R`仍是原响应安全损失，`G`仍是原读取、KL、半径和正则项。原始硬最大值目标在每步和最终端点并列报告，不能将两个不同目标的数值直接当作改善幅度比较。

Adam学习率固定1e-5，betas=(0.9,0.999)，epsilon=1e-8，全局梯度L2裁剪1，系数盒±0.125；本次新拟合的动量预先清零，偏差修正使用本轮1–8步。冻结模型、LoRA-A、原V、写前路由、84态prepared/raw与原缓存响应/logits参考，只更新216个系数。

聚合改变、额外训练与动量重启不是匹配因果对照，不能据此宣称某个优化器或目标普遍优越。温度不搜索，状态不筛选，中间头不作为替代候选。
