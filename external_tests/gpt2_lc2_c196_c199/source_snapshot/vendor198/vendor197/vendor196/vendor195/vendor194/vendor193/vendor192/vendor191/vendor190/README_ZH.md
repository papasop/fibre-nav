- 固定全部84个已暴露训练态、模型版本、LoRA-A、V、路由、prepared/raw状态与原C155缓存响应/锚分布logit参考。包含历史confirmation命名的状态也属于已暴露训练集。

- 672个系数响应Jacobian块、4032个响应坐标梯度行、5376次标量反传、最多8次LP。这是显式离线训练，不属于在线免校正执行。

- 固定第8步头只接受两轮全84态原生完整门槛及最终FP64重复；输出336条原生/FP64端点响应裕度比较。FP64响应通过不等于完整接受，不新增FP64完整门。
