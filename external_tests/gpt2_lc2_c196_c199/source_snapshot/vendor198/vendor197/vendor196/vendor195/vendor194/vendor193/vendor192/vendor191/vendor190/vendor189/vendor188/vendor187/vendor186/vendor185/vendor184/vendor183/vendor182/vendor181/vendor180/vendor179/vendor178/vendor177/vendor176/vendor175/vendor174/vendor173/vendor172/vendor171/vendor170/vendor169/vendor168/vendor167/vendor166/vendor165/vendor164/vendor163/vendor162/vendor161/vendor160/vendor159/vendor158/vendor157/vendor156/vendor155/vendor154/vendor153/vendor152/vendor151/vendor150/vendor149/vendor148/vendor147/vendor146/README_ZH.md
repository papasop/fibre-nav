## 新目标与固定训练

对每态定义：

`R_i = relu(max(abs(response_i)) / 0.0018 - 1)^2`

`G_i = read_hinge(0.075) + KL_hinge(0.0045) + radius_hinge(20) + 0.001*mean(a^2)`

全84态目标：`J = 0.9*max(R_i) + 0.1*mean(R_i) + mean(G_i)`。

精确最大值并列时，在并列响应坐标和并列状态之间取平均次梯度。各态保护项始终参与均值；不是仅训练失败态。该有限加权目标不保证逐步下降、约束优先级、收敛或最终可行性。

固定12步全批量离线训练，手工 float64 投影 Adam，学习率0.0005，betas=(0.9,0.999)，epsilon=1e-8，聚合梯度 L2 裁剪1，共享控制盒[-0.125,0.125]。不提前停止，不选最佳、中间或恢复检查点。只更新36维共享控制；GPT-2 主干、LoRA-A、原 writer、V、坐标、特征和归一化保持冻结。
