明确区分：

1. 声明参数图内的物理点身份一致。
2. 归档观测向量逐值完全相等。
3. 观测满足原登记重放容差。

第1或第3项成立不自动推出第2项。原生原规则是22维观测最大差≤0.0002、KL绝对差≤5e-6、指标gates一致且物理点身份一致；FP64原规则是22维观测最大差≤2e-9、KL绝对差≤2e-9。FP64原始点哈希另作描述，不新增重放门槛。以上重放规则不改变原生响应0.002等验收门槛。
