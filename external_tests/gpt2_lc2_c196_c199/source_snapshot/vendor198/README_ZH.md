# C198：冻结 C196 的完整模型级重放（CPU）

本包仅用于验证，不训练写入器。C196 的84个已暴露训练态在两轮完整原生验收中通过；C197已审计归档算术。C198重新加载固定GPT-2，在同一程序内进行新的模型测量，不是独立实验室复现，也不测试泛化。

## 运行方式

1. 在Colab CPU环境运行配套 `C198_CPU_LAUNCHER.py`（可复制内容到单元格）。
2. 提示上传时，仅上传一次 `C198_CPU_LAUNCHER_BUNDLE.zip`，不用解压，不上传科研结果包。
3. 原C155–C197共43个科学结果ZIP从固定Drive路径读取，并逐一验证固定SHA256。必要时在启动器的INPUT_PATHS填写原包绝对路径，内容哈希不能改。
4. Drive未挂载时才发起挂载；授权失败仍打包本地失败结果。CPU子进程隐藏GPU，保留Notebook内核的GPU环境。
5. 工作进程上限240分钟；合成自测、依赖安装和打包另计。首次需要联网下载固定GPT-2和固定HF依赖；保留系统PyTorch/NumPy，不安装SciPy。

## 测量顺序

先用不可变C197审计源码重绑42个上游原包并核对原C197。随后加载一次原生FP32 GPT-2，记录新零点与旧参考的差异，但评分与新特征均保留原C155参考。

两轮分别重新检查84个制备态并重新获取84组3147维特征（每组3次模型前向）。每次调用原冻结raw映射并独立构造完整3211维输入；使用新raw坐标重新计算软路由，执行固定显式左和及正向roll1的耦合写入公式。路由不读取状态ID、输入类标签、端点结果或旧权重。

全部168个新提案均在任何写后端点前封存。之后分别测量两轮原C196已封存端点（控制路径）及两轮新提案端点（全流程路径），每条路径保留全部84态。原端点控制只检验端点测量可复现性；不能替代新采特征全流程。两轮新提案不要求与旧提案逐字节相等；其实际完整门槛必须通过，且两轮自身满足原重复测量规则及点身份要求。新提案与归档的差异全部报告。
