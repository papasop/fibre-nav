## 前瞻注册与冻结

固定C196最终第8步头 `7b4811602621506a568c7067bad6dd317c29a2f871a1dbca3684051097df0d4c`，原raw writer、3147/3211特征规则、V、路由均值/尺度/原型、原GPT-2/LoRA-A与原C155 FP32响应/logits参考。

12个已知制备中心（C82/C90，每个已训练类4个中心），每中心使用两档原确认幅度0.125和0.375，每档两条固定新方向，合计48态，xor00/01/11各16态。种子基数199082931；完整ID/种子/幅度/父态名单在PROTOCOL_FROZEN.json中。

方向公式：u为固定种子标准高斯向量；t=u−V.T@(V@u)；delta=指定幅度*t/norm(t)；新坐标=float32(原父态+delta)。V必须满足既定正交性检查，失败直接停止，不修复、不重抽、不缩半径。该共享行空间正交补不自动等于真实局部切空间，也不保证有限步验收。

先固定完整写入流程，再生成并封存全部48坐标；在任何新状态模型测量前完成封存。使用44个绑定原包的非源码JSON/JSONL显式ID、种子和hash/digest字段，加上继承历史哈希、已绑定的制备/raw/C196/C198物理坐标，进行重复检查。任何冲突停止而不替换。检查不涵盖未绑定历史、未记录的访问或外部观察；不能证明全项目非访问或时间顺序。

## 运行顺序

1. 重绑上游原包，独立重建C198的672条记录、168组新特征/路由/提案及504条原生指标算术，核对其已通过的冻结重放判定；不执行科学结果包内源码。
2. 初始化一次固定CPU FP32 GPT-2；新零点只作诊断，评分与特征仍使用原C155参考，不重新设基线。
3. 已知84态前置控制：重新检查制备、提取特征、生成单次冻结提案；封存84个提案后，分别测原C198封存端点及本次新提案。完整检查全部84态。若控制失败，停止在新状态测量之前，报告条件分支结束，不声称完成确认。
4. 控制通过后，两轮分别检查全部48个新制备态、重新采集特征并生成单次提案。即使制备无效，也不删除该态、不改变公式。
5. 全部96个新提案封存后，运行两轮完整端点验收，保留全部失败并检查同态重复测量的一致性。
