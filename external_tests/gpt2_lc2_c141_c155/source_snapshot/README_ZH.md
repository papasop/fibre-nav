## 固定科学范围

仅检查 C152 `cyclic_rate_1e4` step12 更新前位置及其归档 `after-before` 方向，完全复用 C154 的七点：0、±1/4、±1/2、±1。方向不归一化，不更改写入映射或系数箱，不重新挑点。α=0/1 精确保留原 before/after，其他点按原 float64 系数映射后提交 float32。

- 原 FP32：全部84个已暴露训练态，七点及零/+1复测，共756次原生指标和756次功能指标。原生提交之后才调用功能端点；每次同步并检查当前物理坐标快照，防止把合法原生提交误报为功能路径篡改。
- FP64诊断：固定两个已暴露训练态，`xor_11__c141_confirmation_p09_n01_d00` 与 `xor_11__c141_confirmation_p08_n01_d00`，分别来自已知晚期最差态与新增失败态。每态七点及零/+1复测，共18条指标。ID中的 confirmation 不赋予未见状态资格。
- 共1530条指标、3062次模型前向，含原FP32零图卡基线1次和独立FP64零图卡基线1次。无反传、训练、拟合、求解、Jacobian、SVD、教师或在线修复。
- 原FP32门槛：响应 .002、KL .005、读裕度 .05、半径20及原1e-5舍入余量。损失安全尺度继续使用 .0018/.0045/.075。

## FP64的准确含义

先把原模型的完整 FP32 参数数值与浮点 buffer 精确转换为 FP64，整数/布尔 buffer 保持原类型。调用时临时替换整个参数映射；已封存的 float32 图卡坐标仅作精确 double 转换，不重算 float64 写入提案。每次调用后检查原 FP32 模型、参数/缓冲区对象、图卡和非图卡值已恢复。原模型未整体 `.double()`，验收配置也没有改变。

独立执行零图卡 FP64 基线，分别报告：

1. FP64观测相对自身FP64零图卡基线的响应和KL。
2. 同一FP64输出相对原缓存FP32响应均值的响应；KL则明确使用原FP32基线logits转换后在FP64中重新计算的概率分布。
3. 两个响应基线的偏移、分解余量及每坐标轨迹。相同基线偏移在点间差分中抵消，不把基线偏移当成改进。

FP64不是真值、系统误差上界或替代验收；只有两态，不能计算或声称全部84态FP64目标/资格。没有新精度候选被选中或部署。
