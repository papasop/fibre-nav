# C133：有限步长响应分解（CPU）

把 `C133_CPU_LAUNCHER.py` 全文粘贴到 Colab 的一个代码单元运行。提示时只上传一份 `C133_CPU_LAUNCHER_BUNDLE.zip`，无需解压。科学源码位于 BUNDLE 中，启动器不内嵌科学源码。

程序自动挂载 Drive，按固定路径和 SHA256 找到原 C132 科学结果包。也可填写启动器的 `C132_ZIP` 为原包的绝对路径；仍须匹配固定哈希。`SOURCE_ZIP` 只接受本次配套 BUNDLE，不能填写科学结果包。

## 固定工作范围

- 核对原包完整性、原交付源码身份、18个端点评估前的封存绑定、12态坐标身份和全部72条端点记录。
- 不执行原包源码。重建36组提案结果，独立核对半径裁剪、实际 float32 提交点和全部门槛。
- 对6个有局部 Jacobian 的几何构造中心、三臂、两轮，保留36条分解请求；生成24条相对原始 raw 提案的差值分解请求。
- 另6个历史中心只有端点记录，不计算其局部线性项或余项，不用平均 Jacobian 代替局部导数。
- 不可用臂保留请求及空值，不删态、不回退、不选最优结果。

分解恒等式为：

`端点观测 = 写前观测 + 局部 Jacobian × 实际提交增量 + 有限步长余项`。

分别保存响应6坐标与精确读出4坐标的完整向量；KL只核对门槛，不作导数分解。
分别报告裁剪前、裁剪后及实际提交的一阶作用，以及线性裁剪影响、线性舍入影响。
这些阶段未分别测量新端点，因此不能当作有限因果效应。坐标抵消量 `|线性项|+|余项|-|有限变化|` 仅为描述性统计。

## 判定边界

余项按定义包含所有未被归档一阶预测解释的变化，不是纯曲率、不独立验证 AD 准确性，也不提供前向系统误差界。算术恒等式闭合不证明导数和模型测量真实准确、测量时序或非访问。

运行完成只代表分解与归档核对完成，不代表产生新写入器、提升接受率或通过 LC2。保留 C132 原判定。原 C121/C123/C131 等祖先原包不重新打开。

## 运行与输出

只需系统 Python 与 NumPy；不加载 Torch、Transformers 或模型，不执行前向、反传、训练、拟合、方程求解、新 Jacobian 或 SVD。子进程CPU工作上限20分钟，保持Notebook本身的GPU环境变量不变。

成功或失败均封装一个结果总ZIP，包含源码、日志、报告、进度、逐态分解、完整组件数组和清单；自动备份Drive并下载。失败不会被标成完成。
