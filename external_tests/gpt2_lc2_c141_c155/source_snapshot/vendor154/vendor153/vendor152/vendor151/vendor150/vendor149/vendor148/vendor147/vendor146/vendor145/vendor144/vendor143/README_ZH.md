## 训练范围与固定预算

- 原C140的36态 + C141全部48个已暴露确认态 = **84个训练态**，三个已训练输入类各28态。所有状态明确标为training，保留来源角色。原C141失败判定不改写，不把这些状态继续称为未见确认。
- 只训练一个共享36维控制向量 `a`，从原C140固定第12步初始化。每次运行开始时把Adam一、二阶矩重置为零。
- 固定12次全84态更新。每步84个标量损失与梯度均在同一个共享向量处取得；不单独拟合六个失败态、不按输入类选头。
- 手写float64投影Adam：学习率0.0005，betas=(0.9,0.999)，epsilon=1e-8，全梯度L2裁剪1，a逐坐标限制[-0.125,0.125]。
- 沿用C140损失：响应平均+最大平方hinge、安全线0.00125；读裕度安全线0.075、KL安全线0.0045、半径20及0.001*mean(a²)。全84态按 `0.1*mean(L)+0.9/8*log(mean(exp(8L)))` 聚合。
- GPT2主干、LoRA-A、原raw writer、V、原控制、归一化和特征公式固定。临时functional_call只让共享a进入计算图；不更新GPT2/LoRA-A/raw writer。
