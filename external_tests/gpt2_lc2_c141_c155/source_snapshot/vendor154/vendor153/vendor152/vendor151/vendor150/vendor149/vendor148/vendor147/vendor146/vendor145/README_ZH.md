# C145：固定 C143 最终头的全84态方向诊断（CPU）

将 `C145_FIX1_CPU_LAUNCHER.py` 全文粘贴到 Colab 单元运行；提示时只上传一份 `C145_FIX1_CPU_LAUNCHER_BUNDLE.zip`，无需解压。启动器不内嵌科学源码。使用当前 CPU 即可，不要求 GPU。

## 固定实验

1. 固定 C143 最终第12步的36维共享控制，全部84态继续属于已暴露训练数据；复用归档坐标、特征、原 writer、V、归一化与模型版本。
2. 对全部84态的制备/raw/C140/C143四类原生点重放，共336次指标测量。点和门槛身份不一致、观测漂移或制备无效时，在反传之前停止。
3. 全84态功能/原生前向一致性全部通过后，在同一个冻结控制上重新前向并计算168次标量反传：84个原C143目标梯度和84个响应比值 `q=max(abs(response)) / 0.002` 的梯度。
4. 两类方向分别由原目标的全84态聚合梯度，以及 `softmax(32*q)` 加权响应梯度给出；取负梯度并按最大绝对坐标归一化。零或极小梯度标记为无可用方向，使用显式零向量，不任造方向。
5. 两方向均测试正、反号，以及0.0005和0.0015两个固定控制步长。控制盒投影为[-0.125,0.125]，逐项记录投影及真实控制位移。全部8个探测向量、基线和756个物理点在任何探测端点测量之前封存。
6. 全部9配置（含基线）在每个84态上测两轮，共1512次原生指标测量。响应0.002、KL0.005、读裕度0.05、位移预算20均保持原规则。共计划4033次模型前向。

全程不创建优化器、不迭代训练、不构建完整响应Jacobian、不做SVD或方程求解、不新增状态或特征、不选择最优方向/步长/头、不部署。只有离线标量导数与固定探测；不构成在线响应修复。
