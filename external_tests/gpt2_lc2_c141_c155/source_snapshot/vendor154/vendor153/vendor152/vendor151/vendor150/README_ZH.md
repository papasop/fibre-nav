# C150：固定循环跨坐标耦合，CPU 双臂训练实验

本包在 C148 原路由头上测试一项固定结构变化。它不直接关闭 LC2。

## 运行

1. 将 `C150_CPU_LAUNCHER.py` 全文粘贴到一个 Colab 单元格运行。
2. 提示时只上传 `C150_CPU_LAUNCHER_BUNDLE.zip` 一份，无需解压。原科学结果不作为源码上传。
3. 挂载保存原 C143、C145、C146、C147、C148、C149 结果的 Drive；启动器按固定路径及 SHA256 定位，也可填写六个 `Cxxx_ZIP` 绝对路径。
4. 保持 CPU 即可。系统须有 CPU 可用的 PyTorch；缺失时会停止并打包失败记录。固定 HF 依赖安装在隔离目录，保留系统 PyTorch/NumPy。
5. 工作进程上限 240 分钟；协议合成测试上限 40 分钟、绑定测试 10 分钟、实际 Torch 烟测 10 分钟另计。运行中有心跳。
6. 最后仅产生一个科学结果总包，包含日志、全部失败态、源文件、固定头与逐态记录，并尝试备份至 Drive。CPU 速度与网络会影响能否在预算内完成。

## 固定实验

两臂都从原 C148 路由臂固定 step12 初始化，Adam 动量归零。原 V、原路由器、原始写入器及全部 84 个已暴露训练态保持固定。

- 对照：三个局部逐坐标缩放头，108 个参数。
- 实验：相同缩放头加一个固定循环跨坐标块，216 个参数。交叉块全零初始化，因此两臂初始提案完全相同。
- `u = V @ (raw - prepared)`；`w` 由原写前路由得到。
- 对照 `s = (w @ A) * u`。
- 实验 `s = (w @ A_diag) * u + (w @ A_cross) * roll(u, 1)`。
- 两者均提交 `float32(raw + V.T @ s)`。偏移固定为 +1，在原 V 行次序内循环，不搜索配对、温度或图卡。
- 两臂各固定 12 步，全 84 态全批训练；学习率 .0005，原 Adam/梯度裁剪/系数界保持不变。
- 原响应 .002、KL .005、读裕度 .05、提案半径 20 的验收门槛保持不变。训练响应安全值 .0018。
- 有效控制正则为 `.001 * sum(e**2) / 36`；交叉块为零时与原对角正则一致。
- 两臂 step12 及全部 336 个最终点先封存，再做两轮 672 个原生端点评估。
- 每臂须在完整流程和重放一致的前提下，两轮均 84/84 才取得训练资格。中断或不完整比较不能使任一臂取得资格。

计划计数：336 次原生前检，84 次零头功能校验，168 次初始头功能校验，2016 次训练图评估、4032 次标量反传，672 次最终原生端点；含初始化共 6553 次模型前向。没有新准备态、确认态或排除类评估。

## 原包核验的范围

六个科学原包均按已知 SHA256 重新打开并检查内部清单。C149 作为已经封存的先前审计凭据使用，**本轮不声称跨 NumPy 构建独立重跑完整旧审计链**。本轮独立核对：84 态跨 C143/C145/C146/C148 的坐标与完整特征副本、精确注册表与行绑定、实际冻结头/V/路由、C148 实际 step12 张量、336 个原封存点与 672 条原生门槛记录。

制作过程中，旧递归审计在本地 NumPy 2.3.5 对 C145 方向数组的逐元素完全相等检查停止；其 7 个元素最大相差约 1.1e-16。本包保留旧源码原样，不放松旧检查，不重分类原判定。改用上述明确的当前输入核验范围。训练前仍在实际 GPT-2 上重新核对全部 84 态的 prepared/raw/C146/C148 基线、零头及两臂初始功能一致性；漂移会在反传之前阻断。

## 结论边界

C149 显示路由和头已有数值分化，但接受判定未改善，未证明对角控制不可行或跨坐标耦合必需。本实验只检验一个预先固定的耦合假设。参数数量和优化几何有差异，结果不能独立归因于耦合。

不改变五个失败态的分母，不只训练失败子集，不选最佳臂/中间 checkpoint，不部署。即使训练全通过，仍需新的前瞻确认及严格隔离的排除输入评估才能支持后续 LC2 声明。本包始终不把本轮训练判为 LC2 或单折通过。

交付前实际验证范围见 `LOCAL_VALIDATION.json`：真实原包输入核验、合成流程与 NumPy 算术已在本地检查；本地没有 Torch，实际 Torch 张量烟测与 GPT-2 训练须在 Colab 运行，启动器将强制先跑烟测。导入桩测试不属于张量或模型验证。
