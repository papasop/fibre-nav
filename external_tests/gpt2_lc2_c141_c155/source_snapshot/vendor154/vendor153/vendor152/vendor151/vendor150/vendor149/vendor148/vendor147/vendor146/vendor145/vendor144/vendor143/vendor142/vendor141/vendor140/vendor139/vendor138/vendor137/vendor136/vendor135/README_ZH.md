## 固定问题与构造

C134观察到原raw写入的有限端点可通过，而共享零空间投影虽消除一阶响应作用，完整端点仍失败。本次只检验一组预登记的共享行空间系数，不新增残差回归头或状态专属参数。

令 `d = 原raw提案 - 制备坐标`，`N = V.T @ V`，`P = I - N`，其中V是C132既有共享响应矩阵的正交行基。构造：

`u_beta = P @ d + beta * N @ d`。

这里的法向仅相对这个固定共享行空间定义，不是对全部状态局部响应流形的法向认证。系数不根据任何本次测量调整。

固定7个系数：`0, 7/8, 15/16, 31/32, 1, 33/32, 17/16`。

- beta0是原C132投影提案：先复核构造，再保留其原坐标字节。
- beta1是原raw提案，保持原坐标字节；其通过不能算新改善。
- beta大于1表示轻微放大共享行空间成分，而非单纯保留。
- 非raw提案最多做一次固定半径20裁剪，再float32提交。若裁剪生效，它会同时缩放切向与法向；这不再是纯法向调整，报告中明确标记。

## 分母、重放与实测

全部12个C132历史中心保留：6个原几何构造中心与另外6个历史已见输入类中心分别报告。两组都是历史训练/开发数据，没有独立确认或排除输入资格。

先核对三份原包、交付源码身份及C133/C134冻结算术；随后在模型初始化前封存全部84个提案点。加载固定GPT-2 CPU float32与原LoRA参数图，先重放12个制备态和24个原raw/投影端点。完整22维观测误差≤0.0002、KL差≤0.000005，点身份和原门槛判定一致；原C134有对应测量的6态也与其两轮终点核对。

若前置重放不一致，停止系数实测。否则按固定顺序测量12态×7系数×2轮，共168条端点请求。每条都使用同一个最终写入目标和原完整内容、响应、KL、读出及半径门槛，失败保留。

仅对原6个几何中心使用归档局部Jacobian作一阶/余项诊断；另外6态不套用平均导数，不构造新Jacobian。余项不唯一归因于曲率、导数误差或前向数值误差。
