# C140 CPU：扩展36态与响应安全裕度的固定训练

## 运行

下载 `C140_CPU_LAUNCHER.py` 和 `C140_CPU_LAUNCHER_BUNDLE.zip`。将启动器全文粘贴到 Colab 的一个代码单元；提示时只上传一份 BUNDLE.zip，无需解压。源码位于配套 ZIP，启动器保持轻量。使用 CPU 即可。

启动后挂载 Drive，按固定路径和 SHA256 自动定位 C132–C139 八个原科学结果包。文件移动时可在启动器顶部填写各 `C132_ZIP` 至 `C139_ZIP` 绝对路径，内容仍须匹配原哈希。

成功或失败均封装一个结果总包，含源码、日志、冻结输入、逐步更新、逐态梯度、门槛记录和未完成请求；尝试备份到 Drive 并下载。工作进程上限50分钟；合成协议测试上限15分钟，PyTorch图连接测试与固定依赖安装单独计时。不同CPU速度下可能触及上限；触及上限只记录未完成，不能拿中途头替代第12步。

## 固定实验

- 原12个中心和C139全部24个投影制备态共同构成36态训练集，三个已见输入类各12态。全部纳入，不只拟合失败态。
- 从C137固定第24步共享控制开始，重置两个Adam矩；只有一个共享36维向量可训练。原GPT2主干、LoRA-A、原raw写入器、V、特征与归一化不更新。
- 固定12步、每步全部36态、432次逐态标量反传；学习率0.0005，控制逐坐标限于[-1/8,1/8]。损失聚合0.1均值+0.9平滑最大值，保留每态原梯度与实际权重。
- 响应训练安全线收紧到0.00125；验收预算仍为响应0.002、KL0.005、读裕度0.05、写入位移半径20及原浮点容差。训练目标与验收标准分开报告。
- 先核对八原包与C139全部24个坐标/48制备/96端点；再原生重放36态的108个制备/raw/C137点。全部36态零控制和初始控制的功能前向与原生前向一致后才反传。
- 只验收固定第12步。全部108个raw/C137/C140提案先封存，再进行三臂两轮216条原生端点测量。预计工作进程1657次模型前向。
- 保留每态失败与对raw、C137的挽救/破坏对照；不提前停止、不选最佳或恢复检查点、不放宽门槛、不删除失败态、不做端点修复。

## 结论边界

`complete=true` 表示固定请求完成。`fixed_final_training_qualification_passed=true` 还要求第12步两轮全部36态完整接受、控制一致、重复一致。

这36态全部是C140训练数据，历史开发身份只作来源记录。完整训练通过仍不构成独立新态确认或排除输入泛化。下一步必须另行预登记新的未见局部确认，之后仍需隔离的排除输入协议。`LC2_closed=false`、`LC2_single_fold_passed=false`，历史C137/C138/C139判定不改写。

反传通过临时LoRA-B参数替换连接到共享向量，不优化基础模型。自动微分遵循实际float64控制到float32提交图，不是有限精度导数准确性的独立证明。
