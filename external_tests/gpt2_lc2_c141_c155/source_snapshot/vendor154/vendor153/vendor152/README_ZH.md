# C152：固定小步长耦合续训对照（CPU）

## 使用

1. 将 `C152_CPU_LAUNCHER.py` 全文粘贴到 Colab 单元格运行。
2. 提示时只上传一份 `C152_CPU_LAUNCHER_BUNDLE.zip`，无需解压，不要选择科学结果 ZIP。
3. 挂载原 Drive；程序按固定路径及 SHA256 定位 C150、C149、C148、C147、C146、C145、C143 七个原结果包。也可填写七个 `Cxxx_ZIP` 的绝对路径。
4. **不需要 C151 结果包**。C151 的可信审计代码已随包交付，训练前直接重审七个原包中的 C150 算术与实际张量。
5. 保持 CPU 即可。系统需要可用的 PyTorch；固定 HF 依赖安装到隔离目录，保留系统 Torch 与 NumPy。
6. 科学工作进程上限 **240 分钟**；协议测试上限 40 分钟、绑定测试 10 分钟、实际 Torch 烟测 10 分钟另计，依赖安装另设独立上限。运行时每 30 秒有心跳。
7. 科学进程成功或中断均封装一个结果总包，包含日志、报告、源码、固定头、全部状态和更新记录，并尝试备份至 Drive。原科学输入保持只读。

## 本轮只检验学习率

两臂都从原 C150 `routed_cyclic_coupling` 的最终 step12 头完整复制，**保留其非零交叉块**，Adam 一阶和二阶动量都归零。

| 项目 | 原学习率续训臂 | 小步长续训臂 |
|---|---:|---:|
| 名称 | cyclic_rate_5e4 | cyclic_rate_1e4 |
| 学习率 | 5e-4 | 1e-4 |
| 参数 | 3×2×36 = 216 | 3×2×36 = 216 |
| 初始头 | 同一个 C150 最终耦合头 | 同一个 C150 最终耦合头 |
| 训练态 | 全部 84 个已暴露训练态 | 相同 84 态 |
| 固定训练步数 | 12 | 12 |

除学习率外，架构、V、原路由器、状态顺序、目标函数、梯度裁剪、系数界和验收门槛相同；两个系数块均可训练。不缩小为四个失败态子集，不拟合新路由、搜索耦合位置、试验新特征、挑选中间 checkpoint 或部署最佳臂。

`u = V @ (raw - prepared)`；两臂均使用：

```
e = (w[0]*P[0] + w[1]*P[1]) + w[2]*P[2]
s = e[0]*u + e[1]*roll(u, 1)
proposal = float32(raw + V.T @ s)
```

三项混合使用固定的显式左结合 float64 求和，以减少跨 BLAS 的字节差异。两臂使用同一实现；原 C150 的全部初始物理提案仍须逐态核对。循环偏移固定为正向 1。

保留原目标：`J = .9*max(R) + .1*mean(R) + mean(G)`；`R_i = relu(max(abs(response_i))/.0018 - 1)^2`，精确并列最大态平均权重。`G` 保留读取安全值 .075、KL 安全值 .0045、半径 20 以及 `.001*sum(e**2)/36` 的正则。

手工 float64 Adam：betas=(.9,.999)、epsilon=1e-8、完整头梯度 L2 裁剪上限 1、每个系数固定在 [-.125,.125]。学习率不在线调整，不回溯，不用写后观测为推理提案做修补。

## 固定验收流程

- 先重审原 C150：全部 24 次更新、2016 条训练记录、336 个封存点及 672 条原生门槛，保留原判定。
- 实际 GPT-2 上对全部 84 态重放 prepared/raw/C148/C150 基线，共 336 次原生前检。
- 全 84 态零头功能校验与两臂各 84 态初始头功能校验全部通过后，才开始标量反传。漂移在反传前阻断。
- 各臂固定完成 12 步；先封存两个 step12 头及全部 336 个提案，再做四臂两轮共 672 条原生端点评估。
- 最终四臂为 raw、冻结 C150 耦合头、5e-4 续训头、1e-4 续训头。
- 验收门槛仍为响应 .002、KL .005、读裕度 .05、提案半径 20（原舍入 allowance 1e-5）。训练响应安全值仍为 .0018。
- 每臂须在完整流程、重放一致的前提下，两轮均达到 **84/84** 才获得训练资格。不完整比较不使任一臂取得资格。

计划计数：336 次前检、84 次零头校验、168 次初始头校验、2016 次训练图评估、4032 次标量反传、672 次最终原生端点；含模型初始化共 6553 次模型前向。无新状态准备、新确认态或排除类评估。

## 证据边界

1e-4 是根据已暴露训练诊断作出的前瞻实验选择，不是已经证明有效的步长。归档梯度算术一致性不证明真实导数准确，C150 的损失波动也不证明步长就是失败原因。

相对冻结 C150 的改善还包含额外 12 步训练；匹配的两条续训臂用于比较本轮登记的学习率差异。本轮不声称总体学习率优越性、收敛、最优性、可行/不可行性或架构充分性。

C149 仍作为封存的旧审计凭据使用，不重跑更早的整个递归审计链；七个输入以外的上游原 ZIP 未重新打开。所有 84 态继续作为已暴露训练数据，后续独立确认必须使用新的前瞻状态。

**本轮只建立训练资格。即使出现 84/84，也仍须新确认及严格隔离的排除输入评估，不能据此关闭 LC2 或单折。**
