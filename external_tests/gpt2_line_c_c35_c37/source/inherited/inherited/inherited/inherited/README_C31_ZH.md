## 预先固定的流程

1. 从C29精确导入C25+C27冻结写入器、原归一化参数、76个历史训练输入和12个原始准备态；**不导入旧16态做拟合或选择**。
2. 按C15原始代码和固定种子重建参数摘要矩阵。该原始矩阵未包含在C29轻量档案中；这里不是声称恢复了档案里的原张量。先在12个历史准备态重算完整输入，逐一与原缓存比较（最大差≤1e-4）；再以原缓存输入复验C27端点（六维响应差≤2e-6）。失败即停止，不静默替换原规则。
3. 仅使用原76态拟合并冻结历史对照预测器。
4. 生成48个固定新训练态，每路由12个，使用三种已知准备基点和0.375/0.75两种扰动范数。种子预先固定，不按残差或写入结果筛选。允许离线准备态的数值核投影和最多4步响应修正；**不校准C27写入器，也不修复写入后的端点**。
5. 每个准备态只由C27生成一次增量，外部提交后前向测量。保存真实准备参数、输入、写后参数、六维残差和全部门控。
6. 将原76态与新48态合并为124态，拟合第二组残差预测器。方法沿用C30：四类特征、固定岭网格、训练内三折选择，每个验证折单独拟合标准化。两个组都保存所有特征族及训练内自动选择结果。
7. 两组预测器全部冻结后，才生成另外16个固定新种子状态。比较两组在**同一16态**上的预测误差，同时独立报告C27实际写入验收。

本轮不新增嵌套外折估计：训练内三折分数只用于选模型，不能当无偏效果估计；主要比较是冻结后的配对16态。不得用这16态重新选择特征、正则、检查点、扰动幅度或候选。

## 有效性和分母

原76态复用C29的已验证记录；只有12个原基点在本轮重新前向复验。新48+16态只检查**准备态有效性**，不构造教师写入端点，因此不提供额外的正教师可行性证书。

准备失败、路由错误或写入失败仍留在固定分母中，不替换。所有有限的新训练输入/标签按预声明规则进入拟合，包括准备无效的状态；结果同时报告有效准备数、实际完整写入通过数、所有状态的预测误差及有效准备子集的计数。数值非有限时保留不完整实验并停止，不丢弃样本后继续宣称完成。

写入阈值仍为响应0.002、KL 0.005、读取margin 0.05。内容、输出翻转、未选内容保留、响应和KL均按原固定规则测量。所请求输出bit仍由外部提供；B5控制器不参与。

## 看哪些结果

- `HISTORICAL_INPUT_REPLAY.json`：摘要重建、12态输入与端点复验。
- `SUMMARY.json:new_training`：新增训练残差是否真正扩大覆盖。
- `SUMMARY.json:prospective_local_development`：C27原始写入验收，不与预测成功混用。
- `SUMMARY.json:prospective_prediction_comparison`：历史76预测器与扩展124预测器的配对比较。
- `*_PROSPECTIVE_PREDICTIONS.json`：逐状态预测与实际残差。
- `PREDICTORS_FROZEN.json`：冻结时间顺序与真实系数哈希。
- `states/`：真实准备参数、输入和原始写后参数；所有失败记录均保留。

`prediction_error_within_response_budget` 表示残差估计误差，不是修正后端点通过。新的随机种子仍处于同模型、同参数图、同四类XOR任务的开发协议，**不是独立确认，也不是未见输入类别泛化**。
