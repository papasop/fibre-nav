## 离线开发

- 当前 36 个训练状态和训练归一化保持固定，重新前向核验准备态、正参考和输入。
- 从 warm1000 创建新的 AdamW 历史。每轮只优化一个实际操作数路由的分支，在该分支 9 个训练态上累积响应损失及教师增量 MSE。其他分支冻结，防止其旧动量产生旁路更新。
