## 预算导向的数值目标

对选中路由的 15 个训练状态，在当前候选参数点测量 90 个响应残差方程。令 A 是输出层位移到一阶响应变化的线性算子，den 是固定行归一化因子，G 是其归一化 Gram；e=E/den，b=0.0018/den。离线求解的凸对偶目标是：

    0.5 cᵀ G c + 0.5 λ ‖c‖² + eᵀ c + Σ bᵢ |cᵢ|

它对应参数位移范数正则加到响应区间的距离惩罚，而不是到零的距离惩罚。提案方向由原缓存 J/H 与小型系数精确重建。

求解器使用单调重启 FISTA（最多 8192 次）及系数符号分区内的小系统二次精化（最多 128 次），记录实际迭代、目标值、KKT 残差、是否达到数值停止标准和未裁剪线性区间超额。该分区由系数符号决定。

有限 ridge 允许残留的区间惩罚误差。小 KKT 残差只反映这个数值目标的驻点误差，不能证明线性区间可行，也不能证明有限非线性更新合规。未收敛结果明确标记；其候选仍必须通过同样的实际前向门控。

重要区别：参数增量和层范数限制在该数值求解之后通过缩放施加；这不是带这些范数约束的精确联合优化器。缩放可能重新引入超预算残差，必须测量实际 float32 位移和真实端点。

## 比较与接受

目标响应区间是 ±0.0018；实际接受门仍为响应无穷范数漂移 ≤0.002、平均 KL ≤0.005、精确/开发读取目标相对 margin ≥0.05、正确内容、真实输出翻转和未选内容保留。0.0002 的目标缓冲是预声明的工程设置，不是曲率认证界。

每轮在同一个起始头比较三种参数增量半径 0.05/0.10/0.20 × 三种 ridge 1e-6/1e-8/1e-10。层 Frobenius 半径仍为 0.5。每个组合最多八次固定回溯，保留该组合第一个实际可接受候选，再比较全部九个组合。

实际守卫保留当前全部完整通过项、所有非响应门控、全 60 态最大漂移和原 36 态最大漂移；要求完整通过数增加，或平方预算超额评分下降。预算超额评分仅计算 max(drift−0.002,0)，已在预算内的响应不需要继续归零。

排序依次为：完整通过数、最大漂移、平方预算超额、平方漂移、半径/ridge/回溯索引。每个候选实测被选路由 15 态，其他 45 态由未变参数区和固定输入保证不变；真正提交之前前向重测全部 60 态。

最多 16 个新离线校准轮次。只处理仍有训练失败的路由，所以 C21 起点通常会集中于 xor_10。新状态泛化改善并非训练门控的必然结果。
