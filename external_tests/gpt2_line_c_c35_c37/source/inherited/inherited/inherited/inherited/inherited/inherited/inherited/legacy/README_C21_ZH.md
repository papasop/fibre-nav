## 校准和保护

每轮从同一个起始头比较三种增量半径 `[0.05, 0.10, 0.20]` 与三种 ridge `[1e-6, 1e-8, 1e-10]` 的九个组合。半径限制该离线校准方向在训练状态上产生的参数增量；它不改变响应预算。

每个组合最多尝试八个预定回溯尺度，保留该组合第一个实际可接受候选。全部九个组合比较完毕后，按完整通过数、最大响应漂移、平方漂移评分、半径/ridge/回溯索引依次排序。这不是穷举全部尺度后择优。

候选先实测所选路由 15 个训练状态，其余 45 态通过输入和参数区隔离保持不变。提交前重测全部 60 态。守卫保留当前所有完整通过项、所有非响应门控、全 60 态最大漂移和原 36 态最大漂移，并要求通过数或平方漂移评分改善。线性预测只作预筛，实际前向门控决定是否接受。

最多 16 个新校准轮次；每个路由独立保存回溯信任步幅。中断恢复实际已提交检查点，并复用相同头下已保存导数、候选测量和完整审计。无需恢复旧 Adam 历史，本阶段新增 Adam 步数为零。

固定终点标准：平均选定响应的无穷范数漂移 ≤ 0.002，平均 KL ≤ 0.005，精确及开发读取的目标相对 margin ≥ 0.05，同时要求内容正确、输出真实翻转、未选中内容保留。逐锚点数值另作诊断，不自动替换平均量门控。

在同一组新状态上比较冻结 C20 头与冻结 C21 头。每个在线写入分支仅生成一次提案，再由外部运行时提交并前向验证；无在线 Jacobian、SVD、反向传播、校正、回溯或教师回退。离线校准、状态准备和参考教师构造仍使用外部几何与自动微分。请求输出 bit 仍作为写入器输入。

这是同一 GPT-2、参数域和访问提示下，四个已训练输入类别内的局部状态开发评估；不是未知 XOR 类别、独立模型种子、B5 控制器调度或模型内部原生更新测试。
