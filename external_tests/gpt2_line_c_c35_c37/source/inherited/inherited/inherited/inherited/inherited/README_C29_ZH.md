## 核心量

对每个状态，在C27基线端点theta0处取声明响应Jacobian J，分别重建两组C28端点thetaa。使用实际float32端点相减得到delta，随后在float64中核算：

- e0：C27端点保护响应残差。
- ea：C28端点实际残差。
- J delta：一阶预测响应改变量。
- e0 + J delta：一阶预测终点残差。
- (ea - e0) - J delta：余项；同时包含非线性、浮点误差及Jacobian求值误差，不能独占地归因于曲率。
- cos(-e0, J delta)与cos(-e0, ea-e0)：预测及实际改变量与所需补偿方向的相似性。零向量时记为null。

响应范数与预算仍为原无穷范数和0.002。方向余弦是另一个欧氏诊断量，不替代预算验收。

复用76份训练Jacobian；只在16个已检查开发态的固定C27端点新增诊断Jacobian，每态6行反向导数。不会用这些导数训练写入器。这是外部取证，不是在线写入的新方法。
