1. 在真实 C23 候选上复验固定全部 60 个训练态，以及原始 36 态的 32 个通过项。

7. 路由合格候选按训练结果排序；每个不同头最多全 60 态审计一次。首个全 60 态合格候选才提交真实检查点。路由合格不等于全 60 态通过，也不等于 60/60 功能通过。
