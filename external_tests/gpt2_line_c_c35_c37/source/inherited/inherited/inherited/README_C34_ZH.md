## 检验什么

C33 的预测误差集中在共同响应偏移。C34 检查参数空间中是否存在可复用的低维补偿通道。
每路由固定使用 C31 的 train00、train01、train02（共12态），在其保存的原始写后端点计算响应 Jacobian。
堆叠三份 Jacobian 为 A，以截断 float64 SVD 构造 `B6=A^+ tile(I6,3)` 和 `b1=B6 ones(6)`。
所有基冻结后，评估全部48个 C31 新训练态及已检查的16个 C31 开发态。
单独报告12个构造态、36个未用于构造的训练态和16个已检查开发态。

对每态先重放保存的原始端点，再比较两种事后候选：

- 固定1维方向乘以负的**实测原始残差均值**；
- 固定6维基乘以负的**实测原始六维残差**。

每个候选只构造一次，请求的 float64 参数增量欧氏范数上限固定0.05（径向截断），不搜索步长、不回溯、不做迭代修正。
float32 加法后的实际参数位移范数另外报告，可能存在舍入差异。
float32 加法后的实际参数张量会保存；真正执行前向并逐项检查内容、翻转、未选内容、响应、KL、精确和开发 margin。
预算仍为0.002/0.005/0.05。构造基没有加入读取梯度约束，内容保持必须由实际门控检验。

**这是离线 oracle 响应补偿，不是无在线校正的学习写入器。**
系数来自原始写后状态的实测响应；没有学习系数模型，没有新状态或独立种子验证，没有 B5 控制器实验，LC1 不闭合。
即便成功，也只说明在声明的基、系数来源、状态与半径范围内，实际有限补偿有效。
失败也不能推出其他基、参数范围或一般补偿不可行。
