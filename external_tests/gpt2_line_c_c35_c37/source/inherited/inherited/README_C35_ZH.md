## 固定协议

原 C25/C27 写入器、C34 的每路由6维补偿基均冻结。
每路由的3个 C34 构造态（共12态）提供固定几何先验：平均写后参数点、平均残差、平均响应 Jacobian。
这些已知训练点构成固定先验，不进入校准交叉验证的验证目标。
其余每路由9态（共36态）训练六维残差校准头；3折选择5个预声明岭强度，所有标准化仅在拟合折计算。
主臂必须选择一个岭校准头；未经校准的几何预测是单独报告的对照，不根据测试结果替换主臂。
个体准备态是交叉验证单位，已知基础准备态可以跨折出现，不属于独立基础准备态留出。

几何特征为 `g = e_center + J_mean @ (raw_point - point_center)`，
其中 `raw_point = preparation + frozen_core_proposal` **只是未提交的参数坐标计算**。
另用写前准备态的6个响应残差作为校准特征。请求输出 bit 仍是输入，不测试模型自主计算 XOR。
离线将几何特征、标准化和学习到的校准合并为固定仿射系数权重。
部署时读取这些冻结权重做前向矩阵运算，不构建、更新或求解模型 Jacobian。
这些权重来源于离线几何；这不是摆脱几何先验或原生内部更新的证据。

三组是 raw、geometry6、selected6。每态只运行一次冻结核心前向，同时生成三组独立候选。
在第一次写后模型前向之前，将所有候选张量封存并绑定准备态、输入和冻结头哈希。
每臂只提交其最终候选并前向验收，不用其他臂的结果修改或选择候选。
运行时不获取中间 raw 点的模型响应；不反向传播、不求 Jacobian、不调用 SVD、校正器、回溯或教师兜底。
补偿分量的请求 float64 范数上限仍为0.05，经 float32 加法生成最终参数；这是核心提案上的写前组合，不是提交后修复。
