# v1.5.1 — GPTW-V3 zero-upload external reproduction

This release adds a one-cell A100 Colab route for reproducing GPTW-V3 directly
from an immutable public source release. It requires no author ZIP upload and
returns a result archive containing the frozen outputs, run log, environment
metadata, source commit and report checksum.

The scientific protocol, seeds, prompts and gates are unchanged. The new entry
point is a same-cohort external reproduction facility, not an independent
new-cohort confirmation.
