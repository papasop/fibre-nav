# GitHub import notes

This directory is an evidence-archive overlay for
`papasop/neural-fibre-geometry`.

Recommended import:

1. extract the ZIP locally;
2. copy the contents of `neural-fibre-geometry_v1_2_moving_f16_confirmation/`
   into the repository root;
3. preserve any repository `LICENSE` already selected by the owner;
4. review `git diff --stat` and `git status`;
5. commit the archive as one evidence update.

Suggested commit title:

```text
Add v3.2c prospective Moving-Fibre F16 confirmation
```

Suggested release tag:

```text
evidence-v1.2-moving-fibre-f16
```

The package intentionally retains v3.2a and v3.2b under `developmental/` and
places only v3.2c under `confirmed/`. Do not delete the two excluded v3.2c seed
records or rewrite the 14/16 eligibility count as 14/14 attempted seeds.
